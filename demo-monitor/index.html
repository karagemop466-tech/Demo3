Public market data can power a live monitor

Kalshi documents public REST reads for series, events, markets, and order books. The dashboard queries demo hosts directly, shows the source link for each returned event, and leaves values empty on connection or schema errors.

Official market-data guide ↗
⌁

Event rankings need an agreed dollar definition

The REST market schema exposes contract counts and top-of-book quotes. Until gross traded notional or another event-dollar metric is verified, this site labels its calculation as displayed top-of-book value and does not call it volume or total liquidity.

See the open measurement question →
◷

Price movement and resolution are observable

The dashboard offers timestamped price charts, depth by price, and a browser watchlist. REST candles provide minute/hour/day bars; seconds-range history is collected only while a page is open. Settlement results are displayed as the API returns them.

Official candlestick schema ↗
▣

Portfolio sync and real demo orders are intentionally gated

Private account endpoints and order entry require signed API requests. No credentials were present in the repository, so this static site never stores a private key or sends a trade. Use the paper mode to test the UI without representing it as a Kalshi fill.
