Trade execution

Order placement is implemented against the current endpoint — the legacy /portfolio/orders writes were removed by Kalshi and return 410 Gone (Create Order (V2)).

StepWhat happens
1. GateWorkflow input place_orders = true and every order spec carries "confirm": "I_ACCEPT_DEMO_MONEY_IS_FAKE".
2. EnvironmentDemo host only. Production orders are refused by the script.
3. EndpointPOST /trade-api/v2/portfolio/events/orders with side: bid|ask, count, price, time_in_force, self_trade_prevention_type.
4. Price gridPrices are snapped onto the market's own price_ranges; off-grid prices are rejected with invalid_price.
5. LogEvery request, response and HTTP status is appended to data/trade-log.jsonl so performance can be recomputed from the log alone.
