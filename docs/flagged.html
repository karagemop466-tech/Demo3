Things a reader should not assume

  • A blank cell does not mean zero. It means the API did not return the field, or the data needs a key.
  • A "snapshot" label means the last successful hour, not a streaming socket.
  • An order suggestion is not a recommendation to trade; it is a rule output with its inputs printed.
  • data/dashboard.json and data/resolutions-compact.json are the only artifacts the site reads; both are rebuilt from API responses by the workflow and their source fields point at the exact request.
