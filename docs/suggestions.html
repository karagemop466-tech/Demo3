Suggestions for review

Proposals to improve decision-making, nothing more. Each one carries its cost, its dependency and whether it can be undone. Choose the paths you want before anything is implemented — the selections stay in your browser and can be exported as a JSON brief.

How to use this page: accept, defer or reject each suggestion, add an optional note, then Export my decisions. Nothing is transmitted anywhere; the file is produced locally from your choices.

Deliberately not proposed

IdeaWhy not
Scraping kalshi.com's UI for a "total dollars" figure Not an official API field; unverifiable and fragile. Use volume_fp, open_interest_fp and the order book instead.
Calling the demo WebSocket from the browser The handshake needs the private key; shipping it to a static page would leak it.
One "expected profit" number per strategy Requires a probability model the data does not support. Expectancy is published with its caveats instead.
Auto-trading on a schedule from day one No accountable owner for automated order entry (D12) and no agreed P&L definition (D13).
