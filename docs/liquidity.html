Observed snapshots

Every collection run appends one line per tracked market to data/history/<date>.jsonl. Those points are what make second-to-minute resolution possible without a WebSocket.

Why charts cannot be truly tick-by-tick here

The WebSocket handshake is signed even for public market-data channels (Quick Start: WebSockets). A static GitHub Pages site cannot hold a private key, so it cannot stream. The chart therefore draws the API's own candlesticks (1, 60 and 1440-minute periods) plus the hourly observation log. Short windows can legitimately show very few points — the caption always states how many the API returned rather than interpolating.
