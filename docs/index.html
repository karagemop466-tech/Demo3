Kalshi demo dashboard

Live tracking, verified data, and analysis for gas prices, elections, culture, crypto, and golf markets on Kalshi. Every value links to an official source. Anything that could not be confirmed is marked unverified.

Executive summary

  • Kalshi publishes a production Trade API (external-api.kalshi.com/trade-api/v2) and a separate demo API. Credentials do not cross environments, and Kalshi warns that demo prices may not reflect real markets. source source
  • Market data (markets, events, orderbooks, candlesticks) is documented as unauthenticated. Portfolio and trading endpoints require an API key and a request signature. source source
  • Each contract pays $1 to the winning side. Results are yes, no, or scalar. Three settled gas markets (2026-11-16) all resolved YES. source source
  • The API has no dollar-volume field. Rankings here use contracts traded, and this is an open question. source
  • Several culture, golf, and elections series name non-official settlement sources. These are the highest resolution risk. See Flagged for review.
  • Portfolio analysis and trade execution are not done. No demo API key exists in this workspace, and nothing was traded.
  • The live panels call the public API from your browser. Whether your browser is allowed to read it (CORS) is unverified, and the page shows a banner if it cannot.
