PRIVATE ACCOUNT DATA

Demo portfolio

Portfolio performance cannot be queried anonymously. No account data is fabricated or stored in this static page.

AUTH REQUIRED
🔒

Secure account connection is not configured

Kalshi documents authenticated endpoints for balances, positions, fills, and orders. Signing requests requires an API key and private key. A GitHub Pages frontend is public; embedding a private key here would expose it. This build does not collect credentials or sign requests in the browser.

Safe path: deploy a separate private backend that stores the key as a secret, signs only allowlisted demo requests, enforces read-only scope for portfolio analysis, and requires separate explicit approval before an order is sent.
