Executive summary What this site is

This project collects, organizes, and analyzes Kalshi demo exchange data for five topic categories: gas prices, elections, culture, crypto, and golf. It tracks live events until they resolve (outcome yes/no), monitors contract-price movements on a time-axis graph, shows current liquidity (how many contracts are available at a given price), and provides pages for portfolio performance, trade execution, improvement suggestions, and a decision-readiness Q&A.

Data sources (official)

  • Trade API (REST): https://external-api.demo.kalshi.co/trade-api/v2 (recommended demo endpoint)
  • Also supported: https://demo-api.kalshi.co/trade-api/v2
  • WebSocket API: external-api-ws.demo.kalshi.co/trade-api/ws/v2 and demo-api.kalshi.co/trade-api/ws/v2
No manual input required from you. This session gathered data directly from the official Kalshi demo API, built the site, and prepared it for GitHub Pages. Where the demo API returned no data (gas prices, golf in the sampled pages), values are intentionally left blank and flagged — nothing is inferred.
