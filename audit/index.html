Method and result definitions

Official Kalshi docs (docs.kalshi.com) read in full on the checked date; live Kalshi demo API responses read via the fetch tool (URLs listed per row); committed repo files read directly and cited by path. A row is 'Verified' only when an official source or live response confirms the exact claim. Anything that could not be confirmed is marked 'Not reproduced' and left unverified; no value was inferred or filled in.

  • Verified: Confirmed by an official doc page or a live official API response (exact claim).
  • Partly verified: Some of the claim is confirmed; the rest is unconfirmed or needs qualification.
  • Contradicted: Current official data or committed repo data shows the claim is wrong or stale.
  • Flagged: Not a factual error by itself, but an irregularity or decision needed for review.
  • Not reproduced: Could not be checked from this environment; left unverified and not used.

Live values were read through the fetch tool on 2026-11-20. Market values change continuously, so a live value is evidence of what the API returned at that moment, not a quote. Not investment advice.
