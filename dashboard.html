3 · Live swing alerts (≥ $0.10 in either direction)

Every tracked contract is polled for price swings of $0.10 or more in either direction. Alerts stream into two real-time scrolling chats: all events and the model picks filter (a labeled high-ROI heuristic, not a verified ROI predictor). Each alert links its exact official market/event API record; candidate external causes are left blank and flagged because no verified external cause link exists (never inferred).

High-ROI heuristic uses only exchange-reported fields: 45% relative move, 35% liquidity (volume + open interest, log-scaled), 20% bid/ask spread tightness; threshold 0.25. It is a labeled preference, not a verified predictor — see Methodology and the Flagged for review page.

5 · Demo account (optional) & trading

A Kalshi demo API key (from demo.kalshi.co → Account Settings → API Keys; see API keys) enables live demo trading and portfolio reads. Without a key the ticket runs in paper mode (simulated fills at the live best bid/ask — labeled everywhere; nothing is sent to Kalshi). Your key never leaves this browser (localStorage).
