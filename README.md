# Kalshi Demo Tracker (Demo3)

Collect, organize and analyze the **highest-dollar live events on Kalshi's demo exchange** in five
topics — **gas prices, elections, culture, crypto and golf** — track each event to its **yes/no
resolution**, execute and analyze **trades** (demo account or labeled paper mode), and work through
**questions and suggestions** before making decisions.

**Live site:** https://karagemop466-tech.github.io/Demo3/ (GitHub Pages, `main` / root)

## Demo API (verified against official docs)

| Surface | Recommended demo endpoint | Also supported | Source |
|---|---|---|---|
| REST Trade API | `https://external-api.demo.kalshi.co/trade-api/v2` | `https://demo-api.kalshi.co/trade-api/v2` | [docs.kalshi.com/getting_started/demo_env](https://docs.kalshi.com/getting_started/demo_env) |
| WebSocket API | `wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2` | `wss://demo-api.kalshi.co/trade-api/ws/v2` | [docs.kalshi.com/getting_started/demo_env](https://docs.kalshi.com/getting_started/demo_env) |

Public market data (series, events, markets, orderbooks, trades, candlesticks) needs no key:
[Quick start: market data](https://docs.kalshi.com/getting_started/quick_start_market_data).
Trading/reading a portfolio needs a demo API key (RSA-PSS/Ed25519 request signing):
[API keys](https://docs.kalshi.com/getting_started/api_keys).

## Canonical site (root pages)

Generated by `scripts/build_root_site.py` from the verified data registers; checked by
`scripts/verify_root_site.py` (internal links, per-row source discipline, JS syntax).

- `index.html` — executive summary (every row source-linked)
- `dashboard.html` — live events ranking (estimated dollar volume), price chart (x = time in
  seconds/minutes/hours, y = contract price), orderbook liquidity (contracts at each price),
  recent trades, yes/no resolution tracking
- `gas-prices.html` `elections.html` `culture.html` `crypto.html` `golf.html` — category subpages
- `portfolio.html` — performance, trade categorization, strategies by trade type
- `trades.html` — trade execution (demo key or paper mode), blotter, journal
- `questions.html` — decision questions: known / missing / how to discover
- `suggestions.html` — suggestion register with review workflow (decide before implementing)
- `flagged.html` — flagged irregularities & unverified items (nothing blocks the merge)
- `sources.html` — every source used, archives, verification policy
- `repo-review.html` — line-by-line repository review with links
- `methodology.html`, `api-reference.html` — methodology & API reference

## Verification rules

- Every table row links an official source (docs.kalshi.com or the exact demo-API request URL), or
  is left blank and flagged as unverified. Values are **never inferred**.
- Dollar figures derived as *contracts × last price* are labeled **estimates**.
- Demo-environment caveat (official): demo prices/behavior may not reflect real markets
  ([source](https://docs.kalshi.com/getting_started/demo_env)).
