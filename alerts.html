Live swing alerts (≥ $0.10)

Two scrolling chats show contract-price swings of $0.10 or more in either direction. All swings lists every swing. High-ROI screen lists only swings that pass a placeholder screen (the user’s model was not supplied — see Flagged for review F-6D-01). The browser polls the official demo REST endpoint GET /markets?tickers=…&limit=1000 (docs).

  • Detection: a swing is raised when the contract price moved at least $0.10 against the exchange’s own previous_price_dollars (so the first read of a market can already alert) or against this browser’s previous sample. Both directions count.
  • Resolution: when a tracked market settles, a RESOLVED — yes / no message is posted to both chats with the official result, settlement_ts and settlement_value_dollars (market settlement).
  • Cause / event links: each swing links the official event record (GET /events/{event_ticker}) and that event’s official settlement_sources — the websites Kalshi names as the settlement reference for the contract. These are reference links for the trader to check; this site makes no claim about which page caused a move. If the event publishes no settlement source the cell stays blank and is flagged.

How the high-ROI screen works (placeholder)

For an upward swing the screen buys YES at the new price; for a downward swing it buys NO at 1 − new price. Gross payout multiple = (1 − bought price) / bought price. It passes at a multiple of at least 1.00, with volume above zero, outside synthetic exchange-test series. This is arithmetic on official prices before fees; it is not a forecast and not the user’s model.
