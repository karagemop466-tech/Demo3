Reproduce locally 
export KALSHI_API_KEY_ID=...
export KALSHI_PRIVATE_KEY_PEM_PATH=./kalshi_demo_private.pem
python3 scripts/portfolio.py refresh
python3 scripts/analyze.py

Without credentials, portfolio.py falls back to the paper ledger and stamps source_mode="paper"; it never presents paper numbers as exchange numbers.

Known data caveats
  • Fill keys arrive in two shapes (fill_id / trade_id / ticker / market_ticker); the loader aliases them and lists any key it could not map instead of guessing source.
  • Fills before the API cutoff are only in GET /historical/fills; a gap looks like “no trades”, so the summary prints the min_ts covered source.
  • Balance and position snapshots are not transactionally consistent with each other — always read updated_ts alongside source.
  • Do not poll for fills; the balance doc says to drive the UI off the fill WebSocket event source.
