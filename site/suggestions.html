Why a suggestion is not just done

Rule of this project

A change that alters what the site claims (a new metric, a new topic, a live trade) needs your sign-off, because an unreviewed claim becomes a wrong number on a dashboard. Improvements that only add evidence — more tape, more markets, a second API shard read — were implemented without waiting.

What was done unprompted

Ranking by derived dollar volume, the tape-capture pipeline, the resolution ledger, the seconds-axis sampling fallback, the offline capture mode in the trade engine, the paper ledger and this review UI: all built in this session because the requirements demanded a working end-to-end path.

What is waiting, and why

Everything requiring a credential (Q-04), a scope decision (Q-01 culture, Q-02 gas), or a production-rate change (Q-09 rate limits). Each blocked item names the exact thing needed, so unblocking is one action, not a investigation.
