Public endpoints (no auth)

Method & pathKey parametersKey response fieldsSource
GET /series category (exact, case-sensitive; matches any entry in categories), tags, include_volume series[]: ticker, frequency, title, category, categories[], tags[], settlement_sources, fee_type, fee_multiplier, volume_fp Get Series List
GET /series/{series_ticker} include_volume series object (as above) Get Series
GET /markets series_ticker, status (unopened/open/closed/settled), limit, cursor markets[]: ticker, event_ticker, title, status, yes_bid_dollars, yes_ask_dollars, last_price_dollars, volume_fp, volume_24h_fp, open_interest_fp, result (yes/no/empty), close_time, rules_primary Get Markets
GET /markets/{ticker} — Single market object (as above) Get Market
GET /markets/{ticker}/orderbook depth orderbook_fp.yes_dollars/no_dollars: [price_dollars, count_fp] ascending, best last. Bids only. Orderbook Responses
GET /markets/trades ticker, limit (1–1000, default 100), cursor, min_ts/max_ts (seconds) trades[]: trade_id, ticker, count_fp, yes_price_dollars, no_price_dollars, taker_outcome_side, taker_book_side, created_time, is_block_trade Get Trades
GET /series/{series_ticker}/markets/{ticker}/candlesticks start_ts, end_ts (seconds, required), period_interval ∈ {1, 60, 1440} minutes (required), max 5000 periods/request candlesticks[]: end_period_ts, yes_bid/yes_ask/price OHLC (dollars), volume_fp, open_interest_fp Get Market Candlesticks
GET /events series_ticker, status, with_nested_markets, limit (max 200), cursor. No category filter (event category deprecated). events[]: event_ticker, series_ticker, title, sub_title, mutually_exclusive, collateral_return_type, settlement_sources Get Events

Auth & signing

ItemDetailSource
Key typesEd25519 (recommended, default) or RSA-2048 PSS SHA-256. Same headers/pre-sign text for both. API Keys
HeadersKALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP (ms), KALSHI-ACCESS-SIGNATURE (base64). API Keys
Pre-sign texttimestamp + METHOD + path, path without query params. Timestamp within 30s of server clock. API Keys
Rate limitsToken buckets; default 10 tokens/request; Read/Write buckets; 429 → back off. Unauthenticated requests have separate limits. Rate Limits and Tiers
