Status

Live refresh: the refresh job (scripts/refresh_kalshi.py) is written and tested offline. Its scheduled run depends on whether GitHub Actions can reach the Kalshi API, which is not yet verified. Until a run succeeds, the tables show the 2026-11-20 snapshot. Second-level price charts need the WebSocket feed and are not built.

Data: Kalshi public API and official sources listed on the Sources page. Values not confirmed from an official response are left blank and flagged on Flagged for Review. Demo trading is not active (see Demo portfolio).
