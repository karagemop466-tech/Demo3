Where the demo-account numbers would come from (still unverified)

The brief asks to “track the portfolio performance using the kalshi demo account”. That needs an authenticated demo API key; the repository has no credentials, so data/latest/portfolio.json records credentials_missing and every account field is left blank rather than filled with an estimate. Setup path, if the owner adds secrets: demo account → API keys → repository secrets KALSHI_DEMO_API_KEY_ID / KALSHI_DEMO_PRIVATE_KEY → run .github/workflows/trade.yml (mode portfolio).

Simulated ledger only — not a demo-account balance, and not investment advice. Demo prices "may not be reflective of those in real markets" per Kalshi’s demo-environment doc. Generated by scripts/build_paper_desk.py from data/paper/*.json (refreshed by .github/workflows/paper-desk.yml).
