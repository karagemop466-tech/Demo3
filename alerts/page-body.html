Live swing alerts

Two scrolling chat feeds over the highest-dollar live events in the five tracked topics (gas prices, elections, culture, crypto, golf). The rule is exactly the brief's: a contract price that moves ≥ $0.10 in either direction inside the lookback window is one alert. The left chat shows every alert; the right chat shows only the alerts the ROI model likes, where "likes" means the bucket this setup belongs to has a positive measured expectancy after fees in the backtest below. Data is read live in your browser from the Kalshi demo REST API (https://external-api.demo.kalshi.co/trade-api/v2); nothing here sends an order. Demo prices and liquidity are simulated (official demo notice).

      Ranking uses an estimate: contracts traded × the market's notional, because the API publishes no dollar-volume field (labelled everywhere; see methodology). Click any row to load its chart, book and catalysts. Alert counts are per browser session and persist in localStorage.

      5 · Resolution tracking (yes / no, until the event resolves)

      While this page is open, each tracked market is re-polled with the same batch request that drives the alerts; when it stops being open or carries a result, the outcome is posted to the chat and recorded here with its API source. Historical settlements for all five topics are collected continuously by the collector (data/latest/resolutions.json).
