Live price-swing alerts

Every 20 seconds this page asks the official Kalshi demo API for the watched markets. A market whose last traded price moves $0.10 or more between two polls, up or down, produces an alert. The first price seen for each market is only a baseline.

Demo data only. The demo environment's prices may not reflect real markets (official demo docs ↗). Nothing here is investment advice, and no trades are placed by this page.
