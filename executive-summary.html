KALSHI DEMO MARKET MONITOR

Executive summary

What is established, what this prototype can monitor, and what still blocks a defensible decision.

Key facts verified from Kalshi documentation

  • ✓The recommended demo REST API base is https://external-api.demo.kalshi.co/trade-api/v2; Kalshi also lists https://demo-api.kalshi.co/trade-api/v2 as supported.
  • ✓The recommended demo WebSocket is wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2; the supported host is wss://demo-api.kalshi.co/trade-api/ws/v2.
  • ✓Kalshi documents market fields for price, status, volume, open interest, result and settlement metadata; its orderbook returns YES and NO bid levels with contract quantities.
  • ✓Portfolio balance, positions, fills and order operations use authenticated endpoints. The documented WebSocket handshake is authenticated.

Implementation and limitations

  • ✓The dashboard attempts direct, read-only requests to the public demo REST API. It displays no fabricated rows and reports fetch failure if browser CORS/network access prevents data retrieval.
  • ✓It filters open-market discovery for gas prices, elections, culture, crypto and golf using API event metadata and title/ticker text. Topic matches are discovery heuristics, not guaranteed official classifications.
  • !The leading activity view sorts by reported 24-hour contract volume, not dollars. A dollar-turnover formula and its period have not been validated; dollar ranking remains blank and flagged.
  • !Price graphs start capturing when a market is selected and are in-session only. Sampling cadence is selected by the Seconds/Minutes/Hours setting; no historical chart is backfilled or persisted.
  • !Private account performance and trade execution are not connected. This static site does not collect or store private keys and places no orders. A secret-managed backend and explicit approval/safeguards are required.
