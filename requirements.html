Requirements traceability

Every line of the project brief, mapped to the file or page that satisfies it, with the official source used to verify it. Statuses are deliberately conservative: partial means the code exists but a constraint is disclosed on the page, not possible (verified) means the brief asks for something the platform or the API does not allow, with the documentation linked. Nothing on this site is claimed as done without a source; blank or flagged values are never filled in.
