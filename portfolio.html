Portfolio performance

Track performance of trades on the Kalshi demo account, analyze results, categorize every trade, and derive strategies by trade type. Two modes:

  • Live mode — connect a demo API key (dashboard panel or the button below): balance, positions, fills and orders are read from the demo exchange.
  • Paper mode (default, clearly labeled) — simulated fills recorded by Trades against live demo prices, so the full analysis works with no manual input and no credentials. Nothing is sent to Kalshi.

Mode & connection

Paper mode

How to get a demo key (no manual input needed after setup): 1) create a demo account at demo.kalshi.co; 2) Account Settings → API Keys → Create New API Key (Ed25519 or RSA); 3) paste Key ID + PEM above.
